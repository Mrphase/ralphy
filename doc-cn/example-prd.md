# 示例 PRD - 任务列表

这是一个 Markdown 格式的示例 PRD (产品需求文档) 。
Ralphy 将使用您选择的 AI 引擎按顺序执行每一个未选中的任务。

## 最佳实践: 微任务

将大任务拆分为微任务。更小的任务 = 更好的代码质量。

**坏的:** `- [ ] 实现用户身份验证`
**好的:**
```
- [ ] 创建包含 email 和 password 字段的 User 模型
- [ ] 添加密码哈希实用函数
- [ ] 创建注册 API 接口
- [ ] 创建登录 API 接口
- [ ] 添加 session/token 生成
- [ ] 创建登出接口
```

- [ ] 安装生产环境依赖
- [ ] 安装开发依赖

- [ ] 配置 Prettier 进行代码格式化

---

## 用法

使用 ralphy 运行:

```bash
# 使用默认的 markdown 格式
ralphy

# 或者明确指定文件
ralphy --prd example-prd.md
```

## 注意事项

- 当 AI 代理完成任务时，任务会自动标记为完成
- 已完成的任务显示为 `- [x] 任务描述`
- 任务按从上到下的顺序执行
